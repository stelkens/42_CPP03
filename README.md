# CPP03 Inheritance

This project introduces inheritance and exception handling in C++.

## Exercises

* **ex00** — Create a `ClapTrap` class with basic attributes and functionality such as attacking, taking damage and repairing itself.

* **ex01** — Create a `ScavTrap` class that inherits from `ClapTrap` and adds its own behavior and special functionality.

* **ex02** — Create a `FragTrap` class derived from `ClapTrap` with additional functionality.

## Topics

* Inheritance
* Multiple inheritance
* Virtual functions
* Class relationships

## Compilation

```bash
make
```

The project follows the C++98 standard.
